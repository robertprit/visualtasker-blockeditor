# Command Categories

Vorläufige Dokumentation fuer v2.1 / Meilenstein 2.

| Kategorie | Zweck | Beispiele |
|---|---|---|
| `EVENT` | Einstiegspunkte | `EVENT.ON_START` |
| `ACCESSIBILITY` | Inspector-/Accessibility-nahe Erfassung | `ACCESSIBILITY.SCAN_ELEMENT_TREE` |
| `UI` | UI-orientierte Aktionen | `UI.CLICK_TEXT` |
| `VISION` | Screenshot-/Vision-nahe Aktionen | `VISION.SCREENSHOT` |
| `TEXT` | Werte und Reporter | `TEXT_LITERAL` |

Kategorien sind in v2.1 Descriptor-Metadaten. Sie bedeuten noch keine Runtime-Ausfuehrung und keine Permission-Freigabe.
